# Widget Reference

## `createWidget()`

Creates a widget in the `idle` state.

```ts
function createWidget(options: { value: number }): Widget;
```

| Name | Type | Required | Description |
|---|---|---|---|
| `options.value` | `number` | yes | The value to draw. |

## Summary of Widgets

- [`createWidget()`](#createwidget): create a widget.
